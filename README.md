# Print_Bud CRM

Cloud-ready 3D printing business CRM / ERP.

## Product scope

- FDM and Resin printer management across multiple locations
- Material inventory, batch tracking and stock movements
- Customer CRM, quotations and order management
- Production jobs and machine running-hour tracking
- Product costing, markup / margin / fixed-profit pricing
- GST and non-GST billing foundation
- Invoice PDFs, payment tracking, expenses and reports
- Admin, Staff and Accountant roles
- Configurable company settings and custom fields

## Development

See the application package README for local setup and environment configuration.

## Security

Do not commit API keys, Supabase service-role keys, customer information, invoice data or other secrets. GitHub is for source code and migrations; live business data must be stored in a protected database.
